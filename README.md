## 🚀 كيفية الإعداد السريع

### **الخطوة 1: إنشاء حساب GitHub** (5 دقائق)
1. اذهب إلى https://github.com/signup
2. أنشئ حساباً مجانياً
3. أكد بريدك الإلكتروني

### **الخطوة 2: إنشاء مستودع جديد** (2 دقيقة)
1. اذهب إلى https://github.com/new
2. اسم المستودع: `daily-news-digest`
3. اختر "Public" (عام)
4. اضغط "Create repository"

### **الخطوة 3: رفع الملفات** (3 دقائق)
1. في صفحة المستودع، اضغط "Upload files"
2. احفظ هذه الملفات:
   - index.html
   - news_aggregator.py
   - README.md

### **الخطوة 4: تفعيل GitHub Pages** (2 دقيقة)
1. اذهب إلى Settings > Pages
2. اختر Source: Deploy from a branch
3. اختر Branch: main أو master
4. اختر Folder: / (root)
5. Save
